暴躁教練：健身飲食打卡分析器

一、做了什麼

本專案建立了一個基於 LLM 結構化輸出（Structured Output）的飲食分析工具。使用者輸入一日飲食，系統將透過 Pydantic 定義的 NutritionReview 模型，強制 LLM 輸出固定 JSON 格式，評估熱量與蛋白質並給出毒舌改善建議。

二、怎麼執行

  1. 安裝 uv 與本地 Ollama，並準備支援結構化輸出的模型。
  2. 使用 uv 安裝依賴：uv sync
  3. 複製環境變數設定：cp .env.example .env（Windows PowerShell 可用 Copy-Item），確認模型與 API 路徑。
  4. 啟動主程式：uv run python src/main.py

要填什麼？啟動主程式後，終端機會顯示「請輸入今天吃了什麼」，請輸入今天的早餐、午餐、晚餐和零食，例如：

早餐：蛋餅和無糖豆漿；午餐：雞腿便當；晚餐：牛肉麵

這個 GitHub Pages 頁面是專案展示頁，不會直接跳出飲食輸入框；請在下載專案後，於終端機執行上述指令並輸入內容。

預設使用 http://localhost:11434/v1 的 Ollama，也能透過 OPENAI_BASE_URL 改用其他 OpenAI 相容 API。

三、執行結果

輸入範例：早餐：大冰奶、鮪魚蛋餅。午餐：炸排骨便當。下午茶：珍奶。

輸出結果：

{
  "estimated_calories": 2150,
  "protein_level": "嚴重缺乏",
  "roast_comment": "你喝的大冰奶跟珍奶糖分直接爆表，炸排骨的油都可以拿來煎蛋了！蛋白質沒吃夠，精緻澱粉倒是塞滿滿，是打算把肌肉全融化掉嗎？",
  "action_item": "明天起把含糖飲料全部換成無糖豆漿或水，午餐改吃去皮雞肉便當補足蛋白質！"
}

以上數值為展示用範例，實際結果會依模型、份量與輸入內容而不同。

四、AI 使用說明

  • 使用工具：Python、uv、OpenAI Python SDK、Pydantic、Ollama。
  • AI 角色：AI 扮演嚴格但專業的健身教練，針對飲食紀錄提供反向激勵。
  • 結構化輸出：以 Pydantic NutritionReview 作為 response_format，讓回應可被程式穩定解析。
  • 限制：熱量為估算值，不能取代營養師、醫師或個人化醫療建議；毒舌語氣僅作為趣味互動。
